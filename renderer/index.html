Recipes

      

      

      
Import a ComfyUI workflow that contains an Inpaint Canvas node (saved from the ComfyUI UI, or exported in API format) to run it as a recipe. Its result input decides the mode, wired setting outputs become controls in the Settings panel. A workflow in UI format needs a connected ComfyUI (node definitions).

The object tool (O) and layer cutouts run these models inside the app through ONNX Runtime, no ComfyUI needed. Point the folder at a ComfyUI models folder to share the files (they go to its onnx subfolder); the app looks in onnx, sam2 and RMBG there. Plugins

      

      

      
A plugin is a folder with a plugin.json and a JavaScript module in the plugin folder; it can add filter types, side panels, menu actions and tools (docs/PLUGINS.md). Changes to a plugin's files take effect after Reload, no restart needed.

    

    

      
Local files

      

      

      
Every image the editor uploads or receives is kept here, mirroring ComfyUI's input and output folders; the server only holds copies. Removing keeps everything the open documents reference and anything younger than an hour.

Updates

      

      
Updates come from the GitHub releases of DenRakEiw/scumble. A new version is downloaded in the background and installed when you restart from here, or on the next quit. Nothing is sent to GitHub apart from the version request.
