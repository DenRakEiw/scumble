## The seven quick wins

**Q1. A readable line for "mat1 and mat2 shapes cannot be multiplied" (local Flux.2 Klein, BUGS.md, two Reddit
users).** `renderer/editor/host.js` near :5230 prints the execution_error raw ("Error in <node>: <msg>"). Recognise the
torch error on a run of a Flux.2 / Klein recipe (`flux2_klein_local`, `flux3_klein_local`) and say that the text
encoder does not fit the model size (Klein 9B takes qwen_3_8b, 4B qwen_3_4b; FLUX 3 Klein qwen3vl_4b) and to pick the
matching file under Settings. Optional: name the encoder per size in the Klein recipe's description. Test: a generate
gate step with a stubbed execution_error.

**Q2. Realism Pass: a red line when the picture came back unchanged (BUGS.md "not proven to change pixels").**
`realism.js:479` sends only `verify_neural_rendering: true` (the ReShade log). After the answer lands, compare it with
what was sent (a downscaled copy, mean and max difference per channel); nearly equal -> the layer still lands (or not:
decide and say so in the plan's "as built") with a red status line that the pass changed nothing on this card (RTX 30 /
workstation Ampere path). Where: the landing in `host.realismWhole`. Test: the upscale or assistant gate's realism
stubs, an answer equal to the input.

**Q3. Export with a size or a frame larger than one canvas: refuse (BUGS.md "Size limits").** `host.js` `exportCanvas`
(:815) calls `resizeForExport` (:767) and `frameForExport` (~:797) without a limit; `MAX_EXPORT_SIDE` 32768 (:88)
clamps silently (:757, :791). Check with `canvasFits` (`renderer/editor/inpaint_sizelimit.js`, already imported in
host.js) and refuse with `CANVAS_LIMIT_WORDS`; say in the status line when a typed side was clamped. Test: an export
gate step (both backends: it is an export writer path).

**Q4. "N layers saved by a newer Scumble were left out" (BUGS.md, the .scumble review).** `inpaint_canvas.js`
setValue skips an unknown kind without a ref silently (:24444) and a filter layer that throws with a console.warn
(:24432). Count both and show one status line. Test: a document gate step with a layer of an unknown kind.

**Q5. Node: a named reference that does not load stops the run (BUGS.md "Reference layers dropped without a word").**
The node's `nodes.py:777` prints "reference skipped" and the later references move up, so @img points at the wrong
picture; `canvas_state.named_refs` (sent by the app since 26e) is read nowhere in nodes.py. Raise a clear error when
`named_refs` is true and a reference fails to load. Work in a clone of DenRakEiw/ComfyUI-InpaintCanvas (any write in
the live folder hot-reloads the user's ComfyUI), test with `python tools/node_test.py` against the clone if it allows,
else plain Python; the live folder is updated once at the release (fast-forward, then `tools/build_node.py`, which also
brings the #7 fix into the node's editor).

**Q6. Manual: which pack is behind "Selection by text" (`MANUAL.md:119`, issue #7).** comfyui-rmbg's SAM3Segment
(weights in `models/sam3`; on Windows the pack also needs `triton-windows`), or comfyui_segment_anything
(GroundingDINO + SAM); the object tool runs in the app without ComfyUI. Test: `manual_test.js`, the help gate.

**Q7. Agents (MCP), about a day:** letter spacing and line height for `add_text` / `set_text` (`renderer/commands.js`
:2028, :2054; what the text layer already supports); `reopen_closed_tab` (`host.js` :4445 `reopenClosed`); the relight
routes' model sliders (strength, style, lora_strength ..., `commands.js` :1408-1430, as the panel offers them);
`boxes_check` (the Boxes panel's warnings before a paid run, `plugins/boxes/main.js` :96). The tool count changes:

assistant's policy rows (`electron/main/assistant/policy.js`: a new command needs its row or the assistant refuses it).
Tests: commands, relight, boxes, mcp, assistant gates.

**Q8. MOSS-Image (item 47, promised on issue #6; the user, 2026-10-22: "download the moss image weights and integrate
the recipe for 1.50").** First a research step (how it runs on the user's Windows machine: a ComfyUI node pack, a
