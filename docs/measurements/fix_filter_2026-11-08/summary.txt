fix-filter (docs/research/review_full_2026-11-07/verified.json "filters/filter-layer-over-its-own-input"):
a plain filter layer stands for the picture on every path. In renderer/editor/inpaint_canvas.js and renderer/editor/inpaint_filters_gl.js:
  1. filterKey(layer, below, forRun, preview, vp = this.viewPass, plain = false):
     uses vp.crop dimensions when present and pushes !!plain into baseKey when layer.params.limit is set,
     keeping the exact legacy key when no limit is set while separating u_over = 0 (plain) from u_over = 1 (!plain)
     cache entries on limited filter layers.
  2. cropFilterInput(below, { bx0, by0, bw, bh, ix0, iy0, iw, ih }):
     when a region pass reaches outside the document (zoomed-out view / Fit), crops the canvas input to the
     document's pixel box [bx0, by0, bw, bh] and clamps any 1-pixel fractional straddling rim from the
     strictly-inside pixels [ix0, iy0, iw, ih] so spatial/displacement filters (Glass, Lens blur, etc.) clamp
     at the document edge and never sample the empty margin or a subpixel anti-aliased boundary pixel.
  3. filteredCanvas(layer, below, forRun, preview, keepSurface = false, plain = keepSurface):
     passes plain to filterKey; crops below via cropFilterInput when vp.crop is set; sets info.limitOver = !plain
     (a plain filter layer with params.limit mixes the input back in via single-round mix(i, c, w) in the shader,
     matching earlier filters in a chain and the band path, instead of zeroing alpha before ctx.clearRect);
     sets canvas = null when info.limitMissing && canvas === input && !(keepSurface && isGLSurface(canvas)).
     Note on opaque soft Limit: on an opaque picture (alpha === 255), output bytes without a soft Limit (or outside
     the soft ramp, w = 0 or w = 1) are byte-for-byte identical to 2068af87 (diffMax === 0); for a plain filter
     layer with a soft Limit (0 < w < 1) as the last filter in a stack, using single-round mix(i, c, w) (u_over = 0)
     instead of quantizing w * 255 to an 8-bit FBO alpha (u_over = 1) and dividing again in 8-bit source-over
     unifies the last filter with earlier filters in the chain and differs by 1-2 / 255 inside the soft ramp
     (measured maxRamp = 1, maxOutside = 0 against frozen 2068af87 hash deec60b1d3b8... on the 256x256 opaque base).
  4. applyFilterLayer: uses Math.round(layer.opacity * 255) === 255 in plain; restricts rx, ry, rw, rh and
     this.viewPass = fvp to the document box when vp reaches past the document on a non-fill filter layer;
     passes plain to filteredCanvas; returns null if (!out || (plain && out === ctx.canvas));
     calls if (plain) ctx.clearRect(rx, ry, rw, rh) before ctx.drawImage(src, rx, ry, rw, rh).
  5. drawSurfaceTo(ctx, surface, dx, dy, dw, dh, clear = false) & flushFilterChain:
     drawSurfaceTo clears (dx, dy, dw, dh) only inside readSurface's callback on the first piece after
     blitFramebuffer succeeds, and flushFilterChain's fallback clears only inside if (flat), so a lost/replaced
     WebGL context never wipes the canvas below to transparent black.
  6. Frozen 2068af87 references: freeze_base.py, frozen_off.json (--no-tiles), and frozen_on.json (--tiles).
