K21 measurement summary (2026-11-08)
====================================

Scope (docs/PLAN_WASM_BUILD.md §4.8 K21):
- `map_tile_stats` in `crates/px/src/range.rs` (SIMD128 `u16x8` + scalar), exported from `crates/px/src/lib.rs` (ABI 23),
  wrapped in `renderer/editor/px/px.js` (`Px.mapTileStats`, copying only the `[wy0..wy1]` map row window per document
  tile row `ty`, never the 22 MB map), JS twin in `renderer/editor/px/kernels_js.js`, routed as `"kernel"` in
  `renderer/editor/px/kernels.js`.
- `rangeTileClass(vMin, vMax, r, invert)` and `rangeRowBookkeeping(W, H, ty, rowClasses, tile)` in
  `renderer/editor/inpaint_weights.js` (re-exported from `renderer/editor/inpaint_edges.js`).
- `edgeTiles` in `renderer/editor/inpaint_edges.js` delegates to `mapTileStats(...).edge`.
- `cachedMapTileStats(map, m, W, H, snapOn, tau)` in `renderer/editor/inpaint_canvas.js` caches `{ min, max, edge }`
  on `RMAX_CACHE` keyed by `${W}x${H}:${m.join(",")}:${snapOn ? 1 : 0}:${thresh}` (`thresh = Math.round(tau * 65535)`).
- `selectRange` (`source === "depth"`, `tileMode`) classifies each tile per row (`0` empty, `1` full, `2` compute),
  skips posting pool jobs for rows with no `"compute"` tiles (booking full tiles' 255 * pixel count, bounds, and tile
  count via `rangeRowBookkeeping`), and cuts the picture span `[minTx..maxTx]` to compute-class edge tiles.
- `rangeSelectJob` in `renderer/editor/inpaint_worker.js` books `"full"` tiles via `rangeRowBookkeeping` and only runs
  per-pixel evaluation on `"compute"` tiles when `msg.classes` is provided.
