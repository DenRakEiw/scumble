K15 measurement summary (2026-11-09)
====================================

Behaviour change (Question 6.4, stated first per brief.md):
- Sub-byte (`1`, `2`, and `4`-bit) palette TIFF files (`PhotometricInterpretation = 3`) with an extra alpha sample (`ExtraSamples = 1` or `2`) now scale only the alpha sample by `255 / (2^bits - 1)` (`0..1 -> 0..255`, `0..3 -> 0..255`, `0..15 -> 0..255`) while keeping the palette index sample (`0`) raw, for both chunky (`PlanarConfiguration = 1`) and planar (`PlanarConfiguration = 2`) layouts and both straight and premultiplied alpha (`renderer/editor/inpaint_tiff.js:715-716`, `crates/px/src/tiff.rs:379-383`). Previously the sub-byte alpha sample stayed unscaled (`0..1`, `0..3`, `0..15`), so such files opened nearly transparent.

Scope (`docs/PLAN_WASM_BUILD.md` §4.6 K15, §5 row 32; `docs/PLAN_WASM_K10.md` §6):
- `crates/px/src/tiff.rs`:
  - Added `pub fn unpredict(buf, len, rows, row_bytes, pixels, per, bits, le) -> i32` (`:25-170`): horizontal differencing undo (`Predictor = 2`) in place for `bits = 8` (`per = 1, 2, 3, 4` and arbitrary `per >= 1`, with a `u8x16` SIMD prefix-sum fast path for `per = 4` RGBA8 and `per = 1` on `wasm32 + simd128`) and `bits = 16` (`le = true` and `le = false`, reading and writing unaligned `u16` pairs per row without touching row padding bytes).
  - Added `pub fn predict_rgba(rgba, w, rows) -> i32` (`:174-219`): horizontal differencing (`Predictor = 2`) in place for `w * rows * 4` RGBA8 bytes (reverse scan per row so each pixel reads its unpredicted left neighbour, with a `u8x16` SIMD reverse-difference path on `wasm32 + simd128`).
  - Added `pub fn to_rgba(src, src_len, planes, row_bytes, w, rows, spp, bits, le, photometric, alpha_mode, pal, pal_len, out, out_len) -> i32` (`:230-427`): every branch of `inpaint_tiff.js` `toRgba` (`photometric = 0` WhiteIsZero, `1` BlackIsZero, `2` RGB, `3` Palette; `bits = 1, 2, 4, 8, 16`; `le = false, true`; `planes = 1` chunky and `planes = spp` planar; `alpha_mode = 0` none, `1` premultiplied, `2` straight), including dedicated fast paths for chunky RGBA8 straight (`copy_from_slice`, `:307-317`), chunky RGB8 opaque (`:320-332`), and chunky RGBA8 premultiplied (`:335-356`). Unpremultiplying preserves the twin's exact branches (`A = 0 -> RGB 0`, `A = 255 -> pass`, `0 < A < 255 -> min(255, ((c * 255 + (a >> 1)) / a))`, no division by zero), 16-bit scaling at `:374` uses `((v * 2 + 257) / 514) as u8` (matching `inpaint_tiff.js:611` `to8`), and Question 6.4 (`:379-383` inside `sample8`) scales only the alpha sample of sub-byte (`1, 2, 4`-bit) palette+alpha files.
