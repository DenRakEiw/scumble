What changed
  renderer/editor/inpaint_layered.js  readPsd's body is decodePsd(input, inflate, stream); readPsd = decodePsd(.., null),
                                      byte for byte the old path (the merged picture's decode moved into mergedPlanes).
                                      New readPsdStream: the same parse, but each layer's pixels and mask go out as RGBA
                                      bands (onRows) right after its channels are read and its planes are dropped (a
                                      record without pixels drops its planes too); the merged picture only when no layer
                                      has pixels (and the header has an area); onHeader before any channel.
  renderer/editor/inpaint_worker.js   job psd_read: reads the blob itself (the window never holds the bytes), posts the
                                      bands (transferred), answers { doc } or { failed } (the reader's own refusal, shown
                                      without a second read on the window), drops the file's array at its end.
  renderer/editor/inpaint_canvas.js   readLayered sends a PSD to the pool (psdOnPool); readPsdOnPool checks the size from
                                      the header's 26 bytes before the job, writes every band into Layer / Mask pixels as
                                      it arrives (the status line counts the layer and its rows), falls back to the
                                      window's reader only when the job could not run before its first band, stops the
                                      job at its next band when the open is over (a later open; loadFile's `later` reads
                                      _destroyed too, so a closed tab's open is over); loadLayered releases what an open
                                      that is over made; loadLayered / addImageLayers take compositePx.
  renderer/editor/inpaint_pool.js     a stop the caller asked for (onProgress throws, a cancel mid-stream) counts as
                                      `stopped`, not `lost`: only failures switch the pool off.
  tools/layered_test.js / .py         the twins and the gate step (below); tools/native_test.py brings the window to the front.
