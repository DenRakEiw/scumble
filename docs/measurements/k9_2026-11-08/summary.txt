Scope (docs/PLAN_WASM_BUILD.md §4.3 K9):
- `flood_shape` in `crates/px/src/jobs.rs` (exported from `crates/px/src/lib.rs`, ABI 31, wrapped in
  `renderer/editor/px/px.js` `Px.floodShape`, JS twin in `renderer/editor/px/kernels_js.js` `floodShape`, routed in
  `renderer/editor/px/kernels.js` `floodShape`) takes `out_kind: u32` (`1` or `4`) and `cells: Option<&mut [u8]>`
  (`((w + 255) >> 8) * ((h + 255) >> 8)` bytes, one per `256²` cell):
  - `out_kind == 1` (the wand's alpha-tile cut): writes `255` / `0` alpha bytes in place into `rgba[..w * h]` (`view`
    is a `Uint8Array(w * h)`), avoiding 4-byte RGBA writes and 4-byte tile strides.
  - `out_kind == 4` (the bucket's bitmap): writes `[r, g, b, 255]` / `[0, 0, 0, 0]` into `rgba[..w * h * 4]` (`view`
    is a `Uint8ClampedArray(w * h * 4)`), as before.
  - Both paths populate `cells` (`1` for an occupied `256²` cell, `0` for an empty cell) and pass `cells` as the 4th
    argument to `use(view, count, bounds, cells)`.
- `floodOverTiles` in `renderer/editor/inpaint_worker.js` calls `floodShape(..., use, wantTiles ? 1 : 4)`. When
  `wantTiles` (`msg.out === "tiles"`, the wand), it skips empty cells in O(1) (`if (!cells[ty * cols + tx]) continue;`)
  and cuts occupied cells directly from the 1-byte `view` into 64 KB `{ tx, ty, alpha: out.buffer }` tiles (transferred
  via `res.tiles.map((x) => x.alpha)`), which `tilesSource` already reads at `kind: 1` (`SEL_ALPHA`).
- `grow_mask` in `crates/px/src/jobs.rs` (and `growMask` / `growMaskBounds` in `renderer/editor/inpaint_raster.js`,
  `Px.growMask` in `renderer/editor/px/px.js`) clears only the outer margins around `bx0..bx1, by0..by1` instead of
  clearing `bx0..bx1, by0..by1` twice, and when `cells` is given, populates each `256²` cell with `0` (empty),
  `1` (occupied and changed from `d`), or `2` (occupied and all `cw * ch` pixels in the cell are unchanged from `d`).
- `selectionOverTiles` in `renderer/editor/inpaint_worker.js` passes `cells` to `growMaskBounds` on the `"grow"` path:
  unchanged occupied cells (`c === 2`) are skipped in O(1), empty cells (`c === 0`) emit `{ tx, ty, empty: true }` only
  when an old tile existed (`if (name)`), and changed occupied cells (`c === 1`) are cut without re-reading the arena or
  comparing every pixel in JS.
