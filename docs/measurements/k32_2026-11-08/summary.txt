K32 — Stitch worker laps split & mask kernels in Rust (2026-11-08)
==================================================================

Scope (docs/PLAN_WASM_BUILD.md §6 K32)
--------------------------------------
- Six mask kernels in `crates/px/src/maskf.rs` (scalar + wasm32 `simd128` in module `lanes`), exported from `crates/px/src/lib.rs` (ABI bumped 22 -> 23):
  1. `alpha_to_mask(rgba_ptr, dst_ptr, n)`: `((rgba[4*i + 3] as f64) / 255.0) as f32` (SIMD promotes 4 u8 alphas to two `f64x2`, divides by `255.0`, demotes and packs to `f32x4`).
  2. `mask_max_clamp(a_ptr, b_ptr, dst_ptr, n, clamp)`: `Math.max(a[i], b[i])` with optional `Math.min(1, Math.max(0, v))` (`out` may alias `a`, never `b`). Matches V8 `Math.max` / `Math.min` NaN (`0xffc00000`) and signed-zero (`Math.max(-0.0, +0.0) = +0.0`, `Math.max(0, -0.0) = +0.0`) bit-for-bit in both scalar and SIMD.
  3. `mask_one_minus(src_ptr, dst_ptr, n)`: `1.0 - src[i]` in `f32` (in-place when `dst == src`).
  4. `erode_mask(ptr, w, h, r)`: `mask_one_minus` -> `dilate` -> `mask_one_minus` in one wasm call, preserving `1 - (1 - x) != x` in `f32`.
  5. `mask_to_rgba(mask_ptr, dst_ptr, n, mode)`:
     - mode 0 (white): `(255, 255, 255, round(clamp01(m[i]) * 255))`
     - mode 1 (luminance): `(v, v, v, 255)` with `v = round(clamp01(m[i]) * 255)`
     - mode 2 (alphaMask): clears `dst[4*i..4*i+4]` to `(0, 0, 0, 0)` where `m[i] > 0.5`, else sets `dst[4*i+3] = 255`.
  6. `mask_bounds_f32(mask_ptr, w, h, out_ptr)` -> `u32` (1 if any `m > 0.5`, writing `[x0, y0, x1, y1]` with exclusive `x1, y1`; 0 if empty).
- JS twins in `renderer/editor/px/kernels_js.js`, `Px` wrappers in `renderer/editor/px/px.js`, and routed wrappers in `renderer/editor/px/kernels.js` under route `"stitchMask"` (`ROUTE_KINDS.stitchMask = "kernel"`).
- Wired into `renderer/editor/stitch.js` (`maskFromAlpha`, `maskMaxClamped`, `erode`, `maskToCanvas`, `selectionBbox`, `alphaMask`, `fillMasked`, `finishPixels`).
