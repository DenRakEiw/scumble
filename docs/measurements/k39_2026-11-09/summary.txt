Byte effect
-----------
Byte-for-byte identical (`0` changed pixels, identical selection bounds). When `this.selectionInWorker("grow", { n })` returns `null` (when `this.stacks` is false or the worker rejects), `growSelectionNow(n)` (`renderer/editor/inpaint_canvas.js:12748-12755`) now calls `bounds = growMaskBounds(img.data, W, H, n)` instead of `growMask(img.data, W, H, n)` and forwards the returned `bounds` to `this.markSelectionChanged(bounds, done && done.box)`.
- Replaces the four-step JS `growMask` path (`maskBounds` + `feature` + `distTransform` + `write`) AND the subsequent `this.selectionBounds()` rescan inside `this.renderInfo()` (`rescans: 1 -> 0`) with a single `grow_mask` wasm call that writes the grown/shrunk alpha channel in place and returns its `[x0, y0, x1, y1]` bounds (`null` when empty).
- `growMaskBounds` (`renderer/editor/inpaint_raster.js:180-182`) now queries `rustPx("growMask")` (`ROUTE_KINDS.growMask = "kernel"` in `renderer/editor/px/kernels.js:62-65`), so `setRoute("growMask", "js")` routes to `growMask(d, W, H, n, { ms })` + `maskBounds(d, W, H)` while keeping `markSelectionChanged(bounds, ...)` rescan-free (`rescans: 0`).
- Calls `releaseIfLarge()` in `finally`, immediately replacing the window's wasm instance (`releaseDelta: 1`) when a large fallback call grows window wasm memory above `releaseMB` (`256 MiB` default).
