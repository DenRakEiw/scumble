- `crates/px/src/relight.rs` (lines 93–410) and `crates/px/src/lib.rs` (lines 55–57, 819–839): bumped `px_abi_version()`
  42 -> 43; removed `pub const VOGEL_16`, `relight::shadow_march` (`f32`), and the `#[no_mangle] pub unsafe extern "C" fn
  shadow_march(...)` export. Added `march_pixel_scalar` and `#[cfg(target_feature = "simd128")]` `f64x2` SIMD lanes in
  `relight::shadow_march_f64`:
  - Precomputes the row-and-tap invariant `y` march (`iy_rows: [[usize; 64]; 16]` and `max_steps: [usize; 16]`) once per
    row `y` (`cy = sy + 0.5`, breaking at the first step where `cy < 0.0 || cy >= hf` and storing `iy * w`).
  - Under `simd128`, marches two adjacent pixels `(x, x + 1)` in parallel across `0..pairs` (`w & !1`), with any odd
    width tail pixel `x = pairs` handled by `march_pixel_scalar`.
  - Preserves the twin's exact per-pixel formula (`tx = px + cx_t`, `rdx = tx - px`, `step_x = rdx * inv_steps`,
    `sx = px + step_x`) in every lane and in `march_pixel_scalar` so `tx - px` rounding ties match the V8 `f64` twin
    byte-for-byte.
  - Evaluates the twin's exact exit order per step `s in 0..valid_steps` with `active` and `blocked` lane masks:
    1. `exit_sky = f64x2_gt(sz, v_sky_limit)` where `v_sky_limit = v128_bitselect(v_scale, v_inf, f64x2_ge(rdz, v_zero))`
       (`rdz >= 0.0 && sz > scale`).
    2. `cx = f64x2_add(sx, v_half)` and `in_x = v128_and(f64x2_ge(cx, v_zero), f64x2_lt(cx, v_wf))` (`0.0 <= cx < wf`;
       `0.0 <= cy < hf` is already enforced by `s < valid_steps`).
    3. `active = v128_and(v128_andnot(active, exit_sky), in_x)`, breaking early if `!v128_any_true(active)`.
    4. Clamps inactive-X lanes to index `0` via `i32x4_trunc_sat_f64x2_zero(v128_and(cx, in_x))` (breaking the
       loop-carried dependency from `active`/`hit` of step `s - 1` to the load address of step `s`), gathers the two
       `u16` depth samples into SIMD lanes with `v128_load16_lane::<0>` and `v128_load16_lane::<2>`, converts with
       `f64x2_convert_low_i32x4`, and computes `hit = f64x2_gt(map_z, f64x2_add(sz, v_z_bias))`.
    5. Records `blocked = v128_or(blocked, v128_and(active, hit))` and retires blocked lanes via
       `active = v128_andnot(active, hit)`, breaking early if `!v128_any_true(active)`.
