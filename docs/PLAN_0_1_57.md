## What each one does, in one sentence (say behaviour first)

- **63 Outpaint after Extend.** A checkbox in the Canvas tool, *Generate the new border*, makes Extend start the
  selected recipe on the new border right after the canvas grows (the border is selected already); an API recipe asks
  its usual cost question first; the result lands as an ordinary result layer.
- **65 Live scope and clipping warning.** A collapsible *Scope* section in the side panel shows the RGB and luma
  histogram of the visible picture, and the key **J** toggles a view overlay that marks pure black blue and pure
  white red; neither ever reaches an export, a run or the document.
- **68 A frame from a video.** Opening or dropping an .mp4 / .webm / .mov shows a small scrubber dialog (Chromium's
  own `<video>`, no FFmpeg) with frame steps, and the chosen frame becomes a new document, a layer or a reference
  layer.
- **61 Contact shadow.** *Layer > Add Contact Shadow* makes, from the active layer's alpha, a soft shadow layer of its
  own under it (squashed toward the layer's lowest edge, blurred, multiply), with distance / softness / opacity in a
  small dialog; where a depth map exists the shadow fades with the depth difference to the layer's foot; one undo
  step.
