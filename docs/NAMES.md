# Name research (2026-09-07, web search only, not a legal clearance)

Goal: a name that is distinctive, easy to say in English and German, not in use for
image or AI software, and ideally free as a `.com`/`.app` domain. Coined words are the
safest for trademarks; descriptive words ("inpaint", "canvas", "layer") are weak marks
and crowded.

## Shortlist (nothing found in use for software)

| Name | Notes |
|---|---|
| **Brushwright** | No product, repo, company or app found; only a personal Facebook handle. Reads as "the one who makes with the brush", pairs with "-wright" like Lightwright (theatre lighting, different field). Tagline idea: "the inpainting workshop". |
| **Layerwright** | Nothing found. Same pattern, says "layers" which is the product's core. Slightly harder to say. |
| **Pixmend** / **Pixelmend** | Nothing found for either spelling. "Mend" fits inpainting (repairing, replacing parts). Short, memorable, but "Pix-" is a crowded prefix (Pixen, PixMe, Pix4D, Pixlr, Pixelmator). |

## Before deciding (the user does this, 30 minutes)

1. Trademark databases: DPMA (dpma.de, DPMAregister), EUIPO eSearch (euipo.europa.eu),
   USPTO (tmsearch.uspto.gov). Search the name and close spellings in Nice classes 9
   (software) and 42 (SaaS/software services).
2. Domains: `<name>.com`, `.app`, `.io`, `.de`. `.app` is cheap and fits a desktop app.
3. Handles: GitHub org, X/Bluesky, YouTube, npm package name (for the MCP package).
4. App stores are not needed now (desktop installer), but check the Microsoft Store name.
5. Say it out loud in a sentence in both languages, and check the German reading
   (Brushwright: "Brush-reit").

Recommendation: **Brushwright**, with **Layerwright** as the fallback. Register the
domain and the GitHub org before the first public mention.
