# Name research (2026-09-07, web search + RDAP domain lookups, not a legal clearance)

Goal: a name that is distinctive, easy to say in English and German, not in use for
image or AI software, and free as a domain. Coined words are the safest for
trademarks; descriptive words ("inpaint", "canvas", "layer") are weak marks and
crowded.

Domain status was checked live against the registries' RDAP servers (Verisign for
`.com`, Google for `.app`, DENIC for `.de`); "free" means no registration on
2026-09-07, it can change any day.

## Shortlist

| Name | Products found | .com | .app | .de | Notes |
|---|---|---|---|---|---|
| **Brushwright** | none | free | free | free | "the one who makes with the brush"; the -wright pattern (playwright, shipwright) reads as craft. Tagline: "the inpainting workshop". German reading "Brush-reit" is fine. |
| **Paintfold** | none | free | free | free | Coined, short, two clear syllables in both languages. "Fold" hints at layers folding into the picture. Less craft, more product. |
| **Brushfold** | none | free | free | free | Sibling of Paintfold; "brush" is closer to what the tool feels like. |
| **Scumble** | a Roblox squad finder only | taken | free | free | Real painting term: a thin, semi-opaque layer of paint over another, exactly what an inpaint result over the image is. Distinctive and memorable, but .com is gone and English speakers may hear "scum". |
| Underpaint | none | taken | free | free | Painting term for the base layer. Reads well, but describes the opposite of what the app does (we paint over). Backup only. |
| Overbrush | none | taken | free | free | Descriptive, close to generic "overpaint". Backup only. |

## Decision

**Scumble**, chosen by the user on 2026-09-07. To do: register `scumble.app` and
`scumble.de`, run the trademark checks below, claim the GitHub org and the npm name.

## Recommendation (before the decision)

1. **Brushwright** — clean everywhere, craft feel, all three domains free.
2. **Paintfold** — the modern-product alternative, also clean everywhere.
3. **Scumble** — the clever one, if the missing .com does not bother you.

## Before deciding (the user does this, 30 minutes)

1. Trademarks: DPMA (register.dpma.de), EUIPO eSearch (euipo.europa.eu), USPTO
   (tmsearch.uspto.gov). Search the name and close spellings in Nice classes 9
   (software) and 42 (software services).
2. Register the domains the same day: `.com`, `.app`, `.de`. `.app` requires HTTPS,
   which suits a download page.
3. Handles: GitHub org, X/Bluesky, YouTube, npm package name (for the MCP package),
   Microsoft Store name.
4. Say it out loud in a sentence in both languages.
