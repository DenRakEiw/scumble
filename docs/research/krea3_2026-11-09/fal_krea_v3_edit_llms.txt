# Krea 3 Edit

> Edits and combines reference images using text instructions, with optional prompt expansion, output-size controls, and reproducible generation through a seed.


## Overview

- **Endpoint**: `https://fal.run/krea/v3/edit`
- **Model ID**: `krea/v3/edit`
- **Category**: image-to-image
- **Kind**: inference
**Tags**: image editing, multi-reference, image-to-image, krea, krea-3



## Pricing

Billed per megapixel at **$0.025**/MP, counting the output image plus each reference image as the model processes it (references larger than the output are counted at the output’s size). 1 MP = 1024×1024 pixels.

For more details, see [fal.ai pricing](https://fal.ai/pricing).

## API Information

This model can be used via our HTTP API or more conveniently via our client libraries.
See the input and output schema below, as well as the usage examples.


### Input Schema

The API accepts the following input parameters:


- **`prompt`** (`string`, _optional_):
  Edit instruction. Refer to images as <image-1>, <image-2>, ... and regions as @label. May be omitted when a region has a note. Default value: `""`
  - Default: `""`

- **`image_urls`** (`list<string>`, _required_):
  Reference images to edit or combine (1-8). Order sets the <image-N> tags.
  - Array of string
  - Examples: ["https://v3b.fal.media/files/b/0a90b2a1/i89tMXz0SmiwL0ZvbnUvS_image_00240.png"]

- **`regions`** (`list<EditRegion>`, _optional_):
  Bounding boxes on reference images, with optional labels and editing notes. Requires high or ultra reasoning.
  - Array of EditRegion

- **`regional_edit`** (`boolean`, _optional_):
  With high or ultra reasoning, true preserves pixels outside the edit regions on the chosen canvas; false disables automatic region cropping and preservation. Omit to retain automatic preservation. With image_size=auto, keeps the canvas dimensions; an explicit image_size preserves the resized input. Billing uses the generated render dimensions. Use PNG for lossless output.

- **`image_size`** (`ImageSize | Enum`, _optional_):
  Output size, rounded up to multiples of 16, at most 4,220,160 total pixels (1680×2512). auto lets the prompt expander pick the aspect ratio at about 2048×2048. Default value: `auto`
  - Default: `"auto"`
  - One of: ImageSize | Enum

- **`reasoning_level`** (`ReasoningLevelEnum`, _optional_):
  How much effort the prompt expander spends reasoning about the given editing task. Higher reasoning effort means slower generation time. Default value: `"medium"`
  - Default: `"medium"`
  - Options: `"medium"`, `"high"`, `"ultra"`

- **`negative_prompt`** (`string`, _optional_):
  What to keep out of the image. Default value: `""`
  - Default: `""`

- **`seed`** (`integer`, _optional_):
  Latent noise seed. Use a new seed when editing a previous output again.

- **`output_format`** (`OutputFormatEnum`, _optional_):
  Output image format. Default value: `"png"`
  - Default: `"png"`
  - Options: `"png"`, `"jpeg"`

- **`sync_mode`** (`boolean`, _optional_):
  Return images as data URIs instead of saving them in request history.
  - Default: `false`

- **`enable_safety_checker`** (`boolean`, _optional_):
  Check output images for unsafe content. Disabling requires account authorization. Default value: `true`
  - Default: `true`



**Required Parameters Example**:

```json
{
  "image_urls": [
    "https://v3b.fal.media/files/b/0a90b2a1/i89tMXz0SmiwL0ZvbnUvS_image_00240.png"
  ]
}
```

**Full Example**:


### Output Schema

The API returns the following output format:

- **`images`** (`list<ImageFile>`, _required_):
  Generated images.
  - Array of ImageFile

- **`seed`** (`integer`, _required_):
  Latent noise seed used for generation.

- **`prompt`** (`string`, _required_):
  Prompt used for generation, after expansion.

- **`timings`** (`Timings`, _required_):
  Seconds spent in each generation stage; `inference` is the total GPU sampling time.

- **`has_nsfw_concepts`** (`list<boolean>`, _required_):
  Safety result for each image.
  - Array of boolean



**Example Response**:

```json
{
  "images": [
    {
      "url": "",
      "content_type": "image/png",
      "file_name": "z9RV14K95DvU.png",
      "file_size": 4404019
    }
  ],
  "prompt": ""
}
```


## Usage Examples

### cURL

```bash
curl --request POST \
  --url https://fal.run/krea/v3/edit \
  --header "Authorization: Key $FAL_KEY" \
  --header "Content-Type: application/json" \
  --data '{
     "image_urls": [
       "https://v3b.fal.media/files/b/0a90b2a1/i89tMXz0SmiwL0ZvbnUvS_image_00240.png"
     ]
   }'
```

### Python

Ensure you have the Python client installed:

```bash
pip install fal-client
```

Then use the API client to make requests:

```python
import fal_client

def on_queue_update(update):
    if isinstance(update, fal_client.InProgress):
        for log in update.logs:
           print(log["message"])

result = fal_client.subscribe(
    "krea/v3/edit",
    arguments={
        "image_urls": ["https://v3b.fal.media/files/b/0a90b2a1/i89tMXz0SmiwL0ZvbnUvS_image_00240.png"]
    },
    with_logs=True,
    on_queue_update=on_queue_update,
)
print(result)
```

### JavaScript

Ensure you have the JavaScript client installed:

```bash
npm install --save @fal-ai/client
```

Then use the API client to make requests:

```javascript
import { fal } from "@fal-ai/client";

const result = await fal.subscribe("krea/v3/edit", {
  input: {
    image_urls: ["https://v3b.fal.media/files/b/0a90b2a1/i89tMXz0SmiwL0ZvbnUvS_image_00240.png"]
  },
  logs: true,
  onQueueUpdate: (update) => {
    if (update.status === "IN_PROGRESS") {
      update.logs.map((log) => log.message).forEach(console.log);
    }
  },
});
console.log(result.data);
console.log(result.requestId);
```
