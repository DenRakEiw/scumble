Scumble

A free, open-source desktop editor for AI inpainting. Select, say what should be there, and the result comes back as a layer of its own, colour-matched to its surroundings.

Microsoft StoreWindows, signed by Microsoft, updates itself. Or winget install 9NDBTNNMXF2R. Download from GitHubWindows installer, portable zip, Linux AppImage and .deb, and the Claude Desktop extension. Source on GitHubGPL-3.0. A star helps the project get found.

What it does

  • Select by rectangle, brush, point, a text description, or by depth, brightness and colour; type a prompt; the result lands as a new layer with masks, blend modes and undo.
  • Draw boxes on an empty canvas, a caption each, and the whole picture is generated to that layout.
  • Layers, groups, masks, clipping; filter layers (curves, colour grading, HSL, grain, film looks, haze and dehaze on a depth map); text layers; retouch tools (heal, remove, liquify, dodge and burn, frequency separation); in-app cutout and depth maps.
  • Pictures up to 15,000 pixels stay fluid; export to PNG, JPEG, WebP, TIFF, and layered PSD and ORA.
  • The pixels come from your own ComfyUI (local or remote), Comfy Cloud, or image APIs on your own keys (FLUX 3 Image, FLUX.2, GPT Image, Nano Banana, Seedream, Qwen and more). No account, no subscription; keys stay in the OS credential store.
  • Every command is an MCP tool: Claude Desktop installs it with one click from the release's .mcpb, Claude Code and any MCP client drive the window you are looking at.
